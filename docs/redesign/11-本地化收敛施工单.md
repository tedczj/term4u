## 2. 已定边界

1. **路线 A**：删除 Warp Agent UI/SDK/执行层及云协议；禁止用同名空壳、假 URL、空 token、
   `todo!()` 或静默重试修编译。真正本地的值类型移到用途明确的本地模块。
2. 保留 PTY/shell/Ctrl-C、标签页/分栏/窗口恢复、编辑器/文件树/文件搜索/code review、
   本地与项目 workflow、notebook 读写恢复、PATH LSP、本地日志及 bundled skills。
3. 本地 auth 始终无云用户与凭据；不得读取/迁移旧 Warp keyring、`WARP_USER_SECRET`、
   Firebase token 或 refresh token。Term4u keyring 仅供实际需要的本地 secret。
4. 保留历史 migrations、表及旧云数据原始列/JSON；不得通过清表解决加载问题。
   已删除功能的数据不加载到 UI，未知/损坏对象可跳过并记不含正文和密钥的 warning。
5. 保留本地模型的旧 JSON/TOML 字段兼容性。Warp 衍生代码仍为 AGPL，不移入 MIT crate
   冒充原创；不改内部 `warp_*` crate 名，不改产品数据目录和身份。
6. **只支持 macOS**（2026-09-12 用户决定）；Linux 不再是支持平台或验收前提。
   Linux 专属代码、target dependencies、构建/打包脚本和 CI 配置列为后续清理项，本轮 R0
   只登记，不执行批量删除。清理时保留 macOS 使用的共享代码与混合依赖分支。
   删除 Windows 专属实现与 target dependencies，不清洗全仓内联 cfg；
   保留 `crates/command/src/windows.rs`、`crates/warp_util/src/path/windows.rs` 及历史 migrations。
   混合 dependency 条件中的 macOS 所需依赖不可误删；残留平台分支不代表支持承诺。
7. 本地 HTTP/WebSocket 非 loopback 硬拒绝与无 DNS resolver 不得弱化。普通 shell、git、ssh、
   外部 CLI agent 仍是用户主动运行的独立进程；不新增产品级网络限制来替用户管这些命令。
8. 不新增终端 `model.lock()`；沿用已有锁传递，避免重入死锁。
9. 不靠删保留行为测试、加 `#[ignore]`/`#[allow(dead_code)]`、注释测试、放宽断言或 blanket
   allowlist 变绿。测试放独立 `*_tests.rs`。清单中消失测试逐项说明被删功能或迁移后的新 ID。
10. 不覆盖用户已有修改，不删除 `.pi/` 来制造干净工作树；不自行 commit/push、创建 PR/tag、
    改全局环境或安装系统依赖。需要这些操作时先取得授权。测试只使用隔离数据副本。

实现前按任务读取仓库 skills：GUI 使用 `gui-ui-guidelines`/`gui-settings-ui`，Rust 测试使用
`rust-unit-tests`；TUI 使用三个 `tui-*` skill；日志使用 `logging-and-error-reporting`；
实机和跨平台验证使用 `gui-integration-test`、`cross-platform-cloud-verification`。
本文件是执行范围；01–07 章提供设计背景，不重新开启其旧过渡方案。

### 4.3 结构、源码、依赖及产物负证明

```bash

no_match() {
  local rc=0
  "$@" || rc=$?
  if [ "$rc" -ne 1 ]; then
    echo "FAIL: expected no matches (exit 1), got exit $rc" >&2
    return 1
  fi
}
BLACKLIST='sentry|opentelemetry|rudder|warp_server_client|warp_server_auth|warp_multi_agent|cloud_object|firebase|session-sharing|computer_use|voice_input|remote_server|\bmcp\b|rmcp|aws-sdk|aws-smithy'
```

### 4.4 实机、旧数据和网络

- **GUI**：S1–S13 全执行：启动、标签页、分栏、命令、文件树、文本预览、设置、失焦/聚焦、
  睡眠/唤醒、关窗、退出、测试构建崩溃、空闲十分钟。另测 R2 的编辑保存、文件搜索、code review、
  workflow 执行、notebook 编辑后重启与窗口恢复，记录观察而非只截图启动页。
- **TUI**：在真实交互终端运行 `./script/run-tui`，验证启动、输出、Ctrl-C、tab、新 tab、退出，
  保存屏幕文本；有 tmux 用 tmux，否则 PTY。GUI integration 不能代替 TUI 实机。
- **数据**：R2 旧 DB/fixture 的迁移、历史条数及字段对照、写入与重启；只操作隔离副本。
  debug 可用 `WARP_DATA_PROFILE`，release 使用隔离 HOME；数据/日志实际路径从当前实现确认，
  不照抄旧 `.warp-oss` 路径，也不杜撰 `TERM4U_DATA_DIR`。
- **日志**：实际验证正常写入、debug panic 入日志、UI 导出 zip；不要用 SIGSEGV 成功退出
  代替 Rust panic 日志验证。原始日志归档前检查 secret，不展示用户正文。
- **LSP**：伪 PATH server 记录启动参数；PATH 缺失给手工提示；伪 curl/wget/npx/npm 下载调用日志为空。
- **网络**：隔离 HOME/干净 shell/恶意代理下，真实候选 GUI/TUI 各至少运行 60 秒；采集主进程
  和产品启动子进程的 TCP/UDP/WebSocket、DNS 53/853 及后台重试证据；S13 再空闲十分钟。
  零非 loopback 外连、零 DNS、零重试、零待发遥测/崩溃文件，不以“连接被守卫拒绝”代替无请求。
  DNS 必须能归因或在隔离环境捕获，不能只 grep 进程名；采集失败不算零。
- 系统防火墙作为第二道防线需记录拒绝日志并验证为空；修改规则需授权。上述静默运行场景不
  主动运行联网命令；另行验证用户 PTY 子进程可用，不把用户主动网络混进产品零外连指标。
