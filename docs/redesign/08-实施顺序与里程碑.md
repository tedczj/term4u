## 一、阶段关系

<a id="s1-1"></a>

```text
M0–M4：V0 历史实现 ──┐
                    ├─ R0–R6 收敛 + 同一候选验收 ── V1 ── M7 / V2
```

V0 = 本地可用与离线边界；V1 = 云控制面及依赖清理完成；V2 = 品牌、合规材料与对外发布。
