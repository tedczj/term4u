# Term4u 本地化改造文档

Term4u 是 Warp 开源客户端（上游基线 `066ec71b736fc3755e29f58f733deadbdac3d1af`）的
本地化/离线化衍生版本，目前只支持 macOS。**R0 环境与采集条件已落实，R1/R2 已有批次验收；
当前应继续 R3–R6，而不是重做已恢复的本地功能。V1 尚未完成。**

本次文档复核日期：2026-09-13；核对的 `main` 源码为
`eef716cd69b84e0676eb90ad3ee776397aa6b515`。本次是仓库源码、提交差异和已归档证据复核，
不是新的 macOS 实机验收；复核环境为 Linux，未安装 Cargo，未重跑 Rust 构建、测试或网络捕获。

三个证据层次必须分开：

| 基线 | 已归档结论 | 使用边界 |
|---|---|---|
| [R0 本机网络记录](phase1-acceptance/m5-m6/recovery/network-es-20260912/README.md) | 采集校准、系统 DNS 和完整进程树归因通过；指定 debug GUI 620 秒、TUI 65 秒静默观测通过 | 只对应记录中的产物 SHA256，不是最新 release/bundle 或完整 V1 的网络验收 |
| [R1/R2 收敛记录](phase1-acceptance/m5-m6/recovery/r1-r2-20260912/README.md) | `d3fd6fdc` 归档本地运行时、旧 DB、GUI/TUI 和完整 presubmit 的批次验收 | 以 `candidate-source.json`、`current-checkpoint.json` 和原始日志确定输入；不能把这些 PASS 自动转移到后续源码 |
| [最新 GUI shell 回归](phase1-acceptance/m5-m6/recovery/gui-shell-20260913/README.md) | `eef716cd` 修复补全、提示符、clear 和焦点；12 项 focused tests、三组严格 Clippy、macOS 构建/打包有通过记录 | 完整 presubmit 在缺少 `clang-format` 处中断；后续 WGSL、workspace nextest、doc tests 未由这次运行证明通过 |

## 三、术语

| 术语 | 含义 |
|---|---|
| offline_hard | 跨 crate 的离线保护；拒绝非 loopback 出站并禁止外部 DNS 解析 |
| local_only | 本地能力 feature 集，使用 `--no-default-features --features local_only` 构建 |
| 类 A/B/C 测试变化 | 随删除功能消亡 / 编译期断裂 / 行为漂移；保留行为必须恢复测试 |
| 批次验收 | 特定源码/产物在指定范围内通过，不等于整个 V1 或后续 HEAD 通过 |
| WIP | 已保存但未通过完整工程与行为验证的实现，不能当正式交付；也不抹去已归档的局部验收 |
| SOURCE_HEAD | 最终验收冻结的源码提交；所有最终证据对应相同构建输入 |
| V0/V1/V2 | 产品交付阶段；与许可证阶段 1/2 不同 |
| 阶段 2 | 完整 MIT 的独立重实现路线，不属于当前本地化收敛任务 |

## 四、事实与证据纪律

1. 当前任务和验收只有 11 章一份；状态改变时同步 08 章和本索引，不另建相互冲突的清单。
2. 历史数字、PASS 和失败保留其原始提交/时间，不升级为当前证据；阶段通过与最终通过分列。
3. 编译通过不代表行为保留；目录/lock 节点消失不代表依赖与产物负证明通过。
4. 所有最终命令、退出码、原始日志、平台和产物 hash 归档；缺环境或未执行就是未验证。
5. 先修复再冻结源码；修改任何验证输入后重新验证，不能拼接不同候选的 PASS。
