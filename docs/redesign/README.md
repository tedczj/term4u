# Term4u 本地化改造文档

Term4u 是 Warp 开源客户端（上游基线 `066ec71b736fc3755e29f58f733deadbdac3d1af`）的
本地化/离线化衍生版本。当前代码处于 M5/M6 删除后的 WIP 收敛阶段，尚未完成 V1。

2026-09-12：本机 macOS GUI 已完成构建、打包和基本终端实机自测。
启动命令、测试记录及已知限制见 [本机 GUI 运行记录](phase1-acceptance/m5-m6/recovery/local-gui-20260912/progress.md)。
正常退出后的本地窗口/标签页/分栏恢复已通过实测；完整 V1 验收仍未完成。
最新结果见 [GUI 与库测试回归](phase1-acceptance/m5-m6/recovery/gui-extended-20260912/README.md)；下文旧快照保留其原始基线。

**继续开发只使用 [11 · 本地化收敛施工单](11-本地化收敛施工单.md)**：它包含现状、已定边界、
R0–R6、C1–C10、完整验证与 Goal 指令。08 章展示阶段状态；旧 10 章和 handoff 仅保留跳转入口。
01–07、09 章及历史 baseline 是设计/溯源资料，不是并行待办；旧过渡实现不得覆盖 11 章路线 A。

## 二、已定决策

| # | 决策 |
|---|---|
| D1 | 项目定名 **term4u**，不用含上游商标的 warp4u |
| D2 | 项目远端为 `git@github.com:tedczj/term4u.git`；当前施工不重新配置 remote 或重置仓库 |
| D3 | 阶段 1 保持 AGPL-3.0-only + warpui/warpui_core 双 MIT 岛；不为衍生代码改许可证 |
| D4 | **路线 A 已定**：删除 Warp Agent UI/SDK/执行层，不保留无效外壳或云 API 空实现；外部 CLI agent 作为普通 PTY 子进程可运行。未来本地协议留阶段 2 |
| D5 | 设计与验收使用仓库内 Markdown，不发布外部文档站 |
| D6 | 删除云功能后收敛残余依赖；当前不重复执行已完成的大目录删除 |
| D7 | V0 = 本地可用；V1 = 云控制面/依赖清理并通过验收；V2 = 品牌与发布 |
| D8 | 必须验证保留行为、旧数据、测试清单与离线边界，不能仅凭启动或抓网络验收 |
| D9 | 阶段 1 保留 app/ + crates/ 结构；MIT 原创代码预留 crates-local/，不向其中搬运 AGPL 实现 |
| D10 | 只改运行时身份与对外品牌，内部 warp_* crate 名及符号不全仓改名；运行时身份已原子完成 |
| D11 | 只支持 macOS；Linux 专属代码、依赖及构建/CI 配置后续清理，不再要求 Linux 验证。删除 Windows 专属实现/依赖，不全仓清洗内联 cfg。两个源码例外及历史 migrations 按 11 章 §2 保留 |

## 三、术语

| 术语 | 含义 |
|---|---|
| offline_hard | 跨 crate 的离线保护；拒绝非 loopback 出站并禁止外部 DNS 解析 |
| local_only | 本地能力 feature 集，使用 `--no-default-features --features local_only` 构建 |
| 类 A/B/C 测试变化 | 随删除功能消亡 / 编译期断裂 / 行为漂移；保留行为必须恢复测试 |
| WIP | 已保存但未通过完整工程与行为验证的实现，不能当交付 |
| SOURCE_HEAD | 最终验收冻结的源码提交；所有平台和证据对应相同构建输入 |
| V0/V1/V2 | 产品交付阶段；与许可证阶段 1/2 不同 |
| 阶段 2 | 完整 MIT 的独立重实现路线，不属于当前本地化收敛任务 |

## 四、事实与证据纪律

1. 当前任务和验收只有 11 章一份；状态改变时同步 08 章，不另建相互冲突的清单。
2. 历史数字、PASS 和失败保留其原始提交/时间，不升级为当前证据。
3. 编译通过不代表行为保留；目录/lock 节点消失不代表依赖与产物负证明通过。
4. 所有最终命令、退出码、原始日志、平台和产物 hash 归档；缺环境或未执行就是未验证。
5. 先修复再冻结源码；修改任何验证输入后重新验证，不能拼接不同候选的 PASS。
